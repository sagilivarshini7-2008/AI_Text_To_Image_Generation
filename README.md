# 🎨 AI Text-to-Image Generation System

An AI-powered web application that converts natural-language text prompts into images using Artificial Intelligence and the Stable Diffusion v1.5 model.

## 💡 Project Overview

Text-to-image generation allows users to create images simply by describing what they want in natural language.

This project provides a simple and interactive interface where users can enter a text prompt and generate an AI-created image.

## ⭐ Key Features

- 📝 Generate images from text prompts
- 🤖 Uses Stable Diffusion v1.5
- 🚫 Supports negative prompts
- 🖼️ Displays generated images
- 💾 Allows users to download generated images
- 🌐 Simple and interactive Streamlit interface

## 🛠️ Technologies Used

- 🐍 Python 3.11.9
- 🌐 Streamlit
- 🔥 PyTorch
- 🤗 Hugging Face Diffusers
- 🔄 Transformers
- ⚡ Accelerate
- 🖼️ Pillow
