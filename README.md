# 🎨 AI Text-to-Image Generation System

An AI-powered web application that converts natural-language text prompts into images using **Stable Diffusion** and **Streamlit**.

## 🚀 Features

- 📝 Generate images from text prompts
- 🎨 Uses Stable Diffusion v1.5
- 🚫 Supports negative prompts
- 🖼️ Displays generated images
- 💾 Download generated images
- 🌐 Simple and interactive Streamlit interface

## 🛠️ Technologies Used

- Python 3.11.9
- Streamlit
- PyTorch
- Hugging Face Diffusers
- Transformers
- Accelerate
- Pillow
